# Acceptance Criteria

## Must Pass

- [ ] User can complete the main workflow.
- [ ] System handles empty, loading, success, and failure states.
- [ ] Local-only behavior is preserved unless explicitly approved.
- [ ] Errors are visible and actionable.
- [ ] Tests or manual verification steps are documented.

## Out Of Bounds

- [ ] No live trading action is exposed.
- [ ] No broker credentials are required for local testing.
- [ ] No source data is deleted or overwritten without backup.
