START IDEA ORCHESTRATOR

1. Start continuous watcher:

   cd ~/Dev/V2trading_system
   python3 idea_orchestrator.py

2. Submit first idea in another terminal:

   cp docs/projects/idea-orchestrator-system/assets/IDEA_TEMPLATE.md ideas/inbox/idea_2026-05-14_my-idea.md

3. Edit the copied idea file and save it.

4. The orchestrator will:

   - scan ideas/inbox every 30 minutes
   - analyze new idea markdown files
   - move them to ideas/staging
   - write a daily review to idea_reviews/review_YYYY-MM-DD.md around 4:00 AM

5. Morning approval gate:

   Approve:
   mv ideas/staging/idea_*.md ideas/approved/

   Reject:
   mv ideas/staging/idea_*.md ideas/rejected/

6. Around 4:15 AM, approved ideas are:

   - appended to CLAUDE.md
   - appended to docs/projects/idea-orchestrator-system/03_delivery/SESSION_MEMORY.md
   - moved to ideas/implemented
   - committed to git using only orchestrator-managed files

7. Safe one-shot test:

   python3 idea_orchestrator.py --once --no-commit --force-review

Notes:

- This is local-only and paper-safe.
- It does not run trading code.
- It does not overwrite raw market data.
- It does not stage unrelated data/runtime/source changes.
