# QA Checklist

## Code

- [ ] Formatting/lint expectations checked.
- [ ] Tests added or existing tests updated.
- [ ] No unrelated files changed.
- [ ] Error handling checked.

## UI

- [ ] Desktop viewport checked.
- [ ] Mobile/narrow viewport checked when relevant.
- [ ] Empty/loading/error states checked.
- [ ] Text does not overlap.

## Trading Safety

- [ ] No live broker action added.
- [ ] No credential path added.
- [ ] Paper/research labels are clear.
- [ ] Runtime writes are narrow and auditable.
