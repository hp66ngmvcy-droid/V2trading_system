# TAR System Markdown Pack

## Purpose

This pack collects the main TAR system documents for use with Codex, local development, Obsidian, and project review.

TAR stands for a secure, validation-first trading automation research system.

The system should remain paper-only until all validation, audit, security, and human approval gates are complete.

## Core Rule

Do not add live trading execution yet.

The system must support:

- research
- data validation
- feature generation
- strategy testing
- paper execution
- risk control
- audit logging
- scoring
- reporting
- strategy memory
- dashboard review

Live trading must remain disabled.
