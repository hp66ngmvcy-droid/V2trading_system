# External Repositories for Review

This folder contains metadata files (no clones) for external projects the operator wants an AI reviewer to inspect.

Guidance for reviewers:
- Do NOT clone or build anything without explicit permission.
- Focus review on: queue/job architecture, walk-forward patterns, risk gating, position sizing, scoring, and integration ideas for TAR.
- Use the per-repo files below as the starting point.

Repos included:
- freqtrade (https://github.com/freqtrade/freqtrade/tree/develop)
- nautilus_trader (https://github.com/nautechsystems/nautilus_trader)
- Lean (https://github.com/QuantConnect/Lean)
- qlib (https://github.com/microsoft/qlib)
- pybroker (https://github.com/edtechre/pybroker)

Do not run code; provide a review report and suggested integration bullets for TAR.
